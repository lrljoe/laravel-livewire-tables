The Table offers additional configuration to show/hide the Tools/Toolbar sections.  

## Tools
Contains:
- Filter Pills
- Sorting Pills
- The Toolbar

## Toolbar
Contains:
- Actions (if set to Toolbar)
- Column Select dropdown
- Configurable Areas for Toolbar
- Filters Button/Dropdown/Popover
- Pagination dropdown
- Reorder Button
- Search Input
